# MeSHOP — bản cài đặt

Phần mềm quản lý bán hàng (POS) cho cửa hàng điện máy, F&B, karaoke.

Repo này **chỉ chứa file cài đặt và cập nhật**, không chứa mã nguồn.

## Tải về

Vào mục [Releases](https://github.com/meshop86/meshop-releases/releases/latest) và chọn:

| Máy | File |
|---|---|
| Windows | `.msi` |
| macOS Apple Silicon (M1/M2/M3/M4) | `aarch64.dmg` |
| macOS Intel | `x64.dmg` |

Đã cài rồi thì app tự báo khi có bản mới.
